# 🖐️ AI 手势多模态无障碍交流系统

基于 **MediaPipe Hands** 的实时手势识别，结合 **YOLO-World** 物品检测、**Kimi / Moonshot** 大模型对话与 **ASR/TTS** 语音，构建了一套面向无障碍沟通的多模态桌面系统。使用 **PySide6** 打造深色仪表盘界面，支持双手同时识别、静态 + 动态手势、手势方向检测，并在「💬 Kimi 对话 / 🎯 实时监测 / 📜 识别历史 / ⚙ 系统设置 / 🎮 小游戏」五个标签页中完成识别 → 对话 → 语音播报的完整闭环；内置可扩展的「切水果」摄像头小游戏，支持 简单 / 普通 / 困难 / 地狱 四档难度。

## 手势一览

### 静态手势（单 / 双手）

| 手势 | 名称 | 含义 |
|------|------|------|
| ✊ | 握拳 | 坚持 / 加油 / 力量 / 团结 |
| 👍 | 点赞 | 赞赏 / 棒 / 同意 / 没问题 / 搞定 |
| 👎 | 拇指向下 | 差劲 / 反对 / 不同意 / 否定 |
| 👌 | OK / 确认 | 好的 / 确定 / 没问题 |
| ☝️ | 数字 1 | 提示注意 / 稍等一下 / 数字 1 |
| ✌️ | 数字 2 | 胜利 / 和平 / 数字 2 |
| 🖐️ | 数字 5 | 停止 / 拒绝 / 稍等 |
| 👉 | 指向 | 指示方向 / 指向某物 |
| 🫰 | 比心 | 爱你 / 喜欢 / 感谢（小） |
| 🤙 | 打电话 | 联系我 / 打电话 / 呼叫 |
| 🫶 | 双手比心 | 表达爱意 / 感谢（大） |
| — | 数字 3 / 4 | 数字 3 / 数字 4 |

> 注：👌=OK、✌️=数字 2、🖐️=数字 5、☝️=数字 1 在系统中以数字 / OK 形式识别并附带上表语义；👍/👎 由拇指朝向识别；🫰 比心 = 拇指尖与食指尖靠拢成小环；🤙 打电话 = 仅拇指 + 小指伸直；🫶 双手比心由双手食指尖 + 拇指尖靠拢判定。

### 动态手语（SequenceTracker）

| 动作 | 名称 | 说明 |
|------|------|------|
| 👋 | 挥手 Wave | 打招呼 / 再见（水平来回摆动，X 轴方向反转 ≥ 2 次） |
| ⭕ | 画圈 Circle | 强调 / 画圈（掌心绕质心累计转角 ≈ 一圈以上，且轨迹圆度高） |
| ↔️ / ↕️ | 划动 Swipe | 向左 / 右 / 上 / 下 单向平移 |

> **画圈 vs 挥手如何区分**：旧版仅靠「围合面积」单一特征，容易互相误判。现改用**绕质心累计有符号转角 + 等周比**双特征——画圈转角接近 ±360°、等周比高；挥手来回摆动、转角≈0、等周比≈0，两者几乎不再混淆。画面上轨迹线也按手势染色，肉眼即可区分。轨迹采用滑动窗口（默认 48 帧 ≈ 1.6s）并对 MediaPipe 偶发漏检设「丢手宽限期」（连续 8 帧丢手才清空轨迹），避免画圈时一漏检就断笔。

## 安装与运行

### 1. 克隆仓库

```bash
git clone https://github.com/lsq010/hand-gesture-recognition.git
cd hand-gesture-recognition
```

### 2. 创建虚拟环境（推荐）

```bash
python -m venv venv
# Windows
venv\Scripts\activate
# macOS / Linux
source venv/bin/activate
```

### 3. 安装依赖

```bash
pip install -r requirements.txt
```

> ⚠️ **注意**：`mediapipe` 版本必须锁定 `==0.10.14`，因为新版移除了 `solutions` API，本项目依赖该 API 进行手势识别。

### 4. 准备模型权重（物体检测 / CLIP）

- **YOLO-World**：把 `yolov8s-world.pt` 放到项目根目录（已加入 `.gitignore`，不会随仓库提交，请自行保留）。
- **CLIP 文本编码器**：首次运行物体检测时，`ultralytics` 会自动把 CLIP 权重下载到 `weights/clip/`（同样被 `.gitignore` 忽略，无需手动处理）。

### 5. 运行

```bash
python main.py
```

Windows 用户也可直接双击 `run_gui.bat`。

- **启动即登录**：运行 `python main.py` 后，首先弹出 **登录 / 注册** 窗口。未注册过账号时，请先切到「注册」页：填写账号 / 密码 / 确认密码 / **人脸编号**，点「录入人脸」对着摄像头拍 ≥5 张（提示「保存成功」），再点「注册」完成（提示「注册成功」）。之后每次启动可用**密码登录**或**人脸登录**。用未注册账号密码登录会提示「登录失败，请注册」。人脸登录识别成功后，界面会显示「识别为 xxx，即将登录…」并停留约 2 秒（让你看清识别画面）再弹出「欢迎回来」进入主程序。
- 按 **空格 / R** 录音并触发 Kimi 对话，**ESC** 关闭弹窗。（预设场景按钮已移除，无需 `1 / 2` 快捷键。）
- **顶部状态条**：未配置 Key 时显示 `⚠ 缺少 Moonshot API Key`（黄）；配置成功后显示 `✅ Kimi 已配置`（绿）。
- **API Key 安全**：Key 只保存在本次会话内存，**不会**写入数据库或读取环境变量，重启程序后必须重新粘贴输入（避免 Key 泄露后被静默复用）。在「⚙ 系统设置 → API 与配置」点击「保存配置」时，程序会**自动检测 Key 可用性**，并直接提示「✅ Key 使用成功」「❌ Key 使用失败 + 失败原因」；检测失败的 Key 仍可保存，但交流时会提示 Key 错误。**已移除单独的「检测 Key」按钮**（保存时一并检测）。
- **🎮 小游戏**：进入「🎮 小游戏」标签页 → 在左侧游戏列表选择「切水果」→ 在右侧难度行选择 🌱简单 / ⚔️普通 / 🔥困难 / 💀地狱（默认普通）→ 点击「🚀 开始游戏」（若摄像头未开则自动打开）→ 伸出**食指**，在摄像头前移动划过水果即可切开，避开炸弹；游戏中只显示食指指尖轨迹线、并自动隐藏手部骨骼线。可随时「⏸ 暂停 / ▶ 继续」「结束游戏」。

## 技术说明

- **手势识别**：基于 MediaPipe Hands 的 21 个手部关键点，通过指尖相对位置、指间距离、手指计数判断静态手势；`SequenceTracker` 用掌心（Landmark 9）滑动窗口（默认 48 帧 ≈ 1.6s）做动态手势识别，并对 MediaPipe 偶发漏检设「丢手宽限期」（连续 8 帧丢手才清空轨迹），避免画圈时一漏检就断笔。
- **动态手势区分（画圈 vs 挥手）**：用**绕轨迹质心累计有符号转角**（画圈≈±360°、挥手≈0）配合**等周比 circularity = 4π·面积 / 周长²**（圆≈1、来回≈0）双特征判定，取代旧版单一"面积"阈值，几乎不再互相误判；画圈需转角 > 198° 且圆度 > 0.2，挥手需 X 轴反转 ≥ 2 且路程 > 0.3。
- **摄像头初始化（两阶段，不再卡）**：点击「打开摄像头」后在 `CameraInitWorker(QThread)` 后台线程运行，拆为两阶段信号——`cam_ready`（阶段1：仅 VisionEngine + MediaPipe，约 1 秒）立即回主线程出画面并启动实时循环；`extras_ready`（阶段2：YOLO-World / whisper / TTS / Kimi）在后台继续加载，就绪后挂上组件。Windows 端摄像头改用 `cv2.CAP_DSHOW` 后端，首帧延迟从数秒降到数百毫秒。UI 主线程全程不冻结。
- **指向联动**：由手腕关键点 (0) 指向食指尖 (8) 发出射线，与画面中 YOLO 检测框求交，将"用户指着的物体"作为语音/大模型指令的主语，实现自然的"指向 + 说话"组合指令。
- **图形界面**：PySide6（Qt for Python），`QTimer` 驱动帧循环，避免 `while True` 阻塞 UI。
- **中文渲染**：PIL（Pillow）绘制中文字体到画面，解决 OpenCV `putText` 不支持中文的问题。
- **大模型接入**：本地算出「手势 + 指向物体 + 语音」的结构化文本描述，只发文字给 Kimi 进行**纯对话交流**（不再只做语句润色，省 token、低延迟），无 Key 时走规则兜底。
- **🎮 小游戏（切水果）**：`FruitSliceController` 在 `_tick` 帧循环中叠加渲染——水果 / 炸弹从画面底部抛出（按难度调出射速度），用**食指尖（Landmark 8）**在相邻帧间的位移连成切线，与水果 / 炸弹圆形做相交判定切开 / 触发；游戏中 `game_controller.is_running` 时**跳过手掌 / 手指轨迹绘制**，且 `vision_engine.draw_skeleton` 自动置 False 隐藏骨骼线，画面只保留食指指尖切线。难度由 `DifficultyConfig` 定义（生命、时长、炸弹门槛 / 概率、生成间隔、批量、出射速度），经 `main._on_game_start` / `_on_camera_init_done` 传入 `game_controller.start(difficulty)`，难度越高炸弹越频繁（地狱开局即出）。
- **Key 安全**：API Key 仅存于 `MainWindow.api_key` 内存字段，不写数据库、不读环境变量；启动时清空数据库中残留 Key，保证每次运行"干净"，杜绝泄露 Key 被复用。
- **双手逻辑**：`max_num_hands=2`，根据 MediaPipe 返回的 `handedness` 分配到左右手结果栏。

## 常见问题

**Q: 摄像头明明捕获到了双手，但界面右侧只显示一只手？**  
A: 已开启 MediaPipe `max_num_hands=2` 双手检测，并将界面拆为「左手 / 右手」两栏按 `handedness` 分发，可同步识别。

**Q: 运行报错 `No module named 'cv2'`？**  
A: 虚拟环境未装依赖，执行 `pip install -r requirements.txt`。

**Q: 出现 `mediapipe has no attribute 'solutions'`？**  
A: mediapipe 版本过高，执行 `pip install mediapipe==0.10.14`。

**Q: Kimi 对话一直走规则兜底 / 提示未配置 Key？**  
A: 在「⚙ 系统设置 → API 与配置」粘贴 Moonshot API Key 并点「保存配置」，保存时会**自动检测 Key 可用性**并提示「✅ Key 使用成功」或「❌ 失败原因」（单独的「检测 Key」按钮已移除）。注意 **Key 仅本次会话有效，重启程序后必须重新输入**（不再自动从环境变量 / 数据库读取，以防泄露 Key 被静默复用）；即使保存时检测失败，仍可保存，但交流时会提示「Key 错误」。

**Q: 进入小游戏后画面里还有手部骨骼线 / 手掌轨迹线？**  
A: 不会。进入切水果游戏后，`vision_engine.draw_skeleton` 自动置 False 隐藏 21 关键点骨架；同时 `_draw_palm_trail_and_dynamic` 被跳过，画面只保留**食指指尖**划出的切线，避免干扰切水果。游戏结束自动恢复。

**Q: 切水果难度怎么选？炸弹太多 / 太少？**  
A: 在「🎮 小游戏」页右侧难度行选择 🌱简单（5 命 / 炸弹概率 8%）/ ⚔️普通（3 命 / 16%）/ 🔥困难（3 命 / 30%）/ 💀地狱（2 命 / 48%，开局即出炸弹）。难度越高，水果更快更多、炸弹出现越早越频繁；游戏中难度按钮禁用，结束后可重选。

**Q: 点击「打开摄像头」后没有跳到实时监测页？**  
A: 已改为**不自动跳转**——打开摄像头后停留在当前标签页，由你自己点「🎯 实时监测」或「🎮 小游戏」等页面查看画面，使用更自由。

**Q: 启动就让我登录，没账号怎么办？**  
A: 首次使用请切到「注册」页：填账号 / 密码 / 确认密码 / **人脸编号**（数字，如 1001）→ 点「录入人脸」对着摄像头拍至少 5 张（提示「保存成功」）→ 点「注册」即可。之后即可用密码或人脸登录。人脸数据保存在项目根 `faces/` 目录（`face_<编号>_*.jpg`）与 `trainer.yml`，账号密码以 pbkdf2 加盐哈希存于 `auth.db`，**不存明文**。

**Q: 人脸登录识别不出来 / 总失败？**  
A: 人脸登录依赖项目内 `haar/` 目录下的 Haar 级联检测（`haarcascade_frontalface_default.xml`，已随仓库提交）+ LBPH 识别。注意 LBPH 返回的 `conf` 是**匹配距离（越小越像，0=完美匹配）**，判定通过条件为 距离 ≤ `CONF_THRESHOLD`（当前 **90**）；数值越大说明越不像。识别前已对图像做 **CLAHE 直方图均衡**以减弱光照 / 角度影响。请尽量保证注册与登录时光线、角度接近，录入时拍够 5~15 张、人脸居中清晰。若仍失败，可改用密码登录，或适当调高 `auth.py` 里的 `CONF_THRESHOLD`（放宽匹配、但会降低安全性）。识别成功后界面会显示「识别为 xxx，即将登录…」并停留约 2 秒再进入。

**Q: 想换人脸 / 删账号？**  
A: 当前版本未提供图形化账号管理。可直接删除 `auth.db` 重置全部账号，或手动删除 `faces/face_<编号>_*.jpg` 并删除 `trainer.yml` 后重新注册以重建识别模型。

**Q: 物体检测无反应？**  
A: 确认根目录有 `yolov8s-world.pt`，且首次运行可联网（会自动下载 CLIP 权重到 `weights/clip/`）。

**Q: 点击「打开摄像头」后画面出来很慢？**  
A: 已优化为两阶段后台初始化——点击后约 1 秒即可看到手势画面（阶段1：摄像头 + 手势引擎）；YOLO 物体检测 / 语音等重模型在后台约 10 秒自动就绪，期间画面与手势照常可用，不再冻结界面。状态栏会先显示"手势识别中（物体检测/语音后台加载中…）"，就绪后变为"全部组件就绪"。

**Q: 识别历史里怎么看不到上次的记录？**  
A: 出于隐私与轻量考虑，识别历史只在**本次会话**内保留；**关闭程序时自动清空 logs 表**，重新打开后从空白开始。如需长期留存，请在会话内用「导出 CSV」保存。

**Q: 关闭摄像头后画面还停在上一张？**  
A: 已修复——关闭摄像头会清空左侧画面回到纯黑，并重置右侧识别标签与业务状态。
